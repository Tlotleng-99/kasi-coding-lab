# Kasi Coding Lab 🧪

**A personal prototype exploring context-first coding education.**

Kasi Coding Lab teaches core computer science concepts through everyday South African
experiences — starting with what you already understand, and connecting it to the real
CS term, the code, and where it's used in practice.

This is **not** the official DevPath repository — it's a personal experiment and idea
sandbox, built to explore a different structure/approach before bringing ideas back to
the team.

## What's in here

Each lesson follows the same shape:

1. **A familiar moment** — something from everyday life in South Africa
2. **An interactive demo** — play with it, see it behave
3. **The real CS concept** — the proper name, explained simply
4. **Working code** — a real snippet showing the concept in practice
5. **A quick check** — a short practice question to confirm it actually landed

Built as a companion exploration to DevPath, testing a leaner, practice-focused
approach to teaching CS concepts through local context.
